# 교육과정 편성 도우미

초등학교 **2022 개정 교육과정** 기준으로 학교 교육과정 편제표를 짜고, 기준 위반을 자동으로 검토하는 웹앱입니다.
설치 없이 브라우저에서 열리고, 빌드 결과는 `index.html` 파일 하나라서 인터넷이 없는 컴퓨터에서도 파일을 더블클릭해 쓸 수 있습니다.

## 주요 기능

- **개요** — 기준 위반·확인 필요 항목을 한눈에 보고, 누르면 고칠 화면으로 이동
- **편제표·시간배당** — 학년·학기별 시수 입력, 교과(군) ±20% 증감, 체육·예술 감축 불가, 학년군 최소 총 시수 검토
- **창체·자율시간** — 창체 3개 영역 배분, 안전교육 64시간, 정보교육 34시간, 입학 초기 적응 활동, 3~6학년 학교자율시간
- **학사일정·수업일수** — 학기 기간, 법정공휴일(2026·2027학년도 내장), 임시공휴일·재량휴업일, 달력에서 눌러 지정, 수업일수 190일 검토
- **주간 시수 배당** — 요일별 교시 수, 학기 주수, 주당 시수(0.5 단위), 편제와의 차이, 1학기 시간표 예시
- **파일 검토** — 완성된 편제표 파일(엑셀 .xlsx·.csv, 한글 .hwpx, PDF, 이 도구의 JSON)을 올리면 교과별 연간 시수를 읽어 시수 기준 위반을 검토. 읽은 값은 표에서 확인·수정하고, 새 프로젝트로 가져올 수 있음
- **시수 기준 설정** — 기본값은 2022 개정 교육과정. 교과(군) 기준 시수, 감축 불가, 학년군 최소 총 시수, 증감 허용 범위, 수업일수·안전교육·정보교육 기준, 연간 주수를 프로젝트마다 바꿀 수 있음
- **인쇄·내보내기** — A4 가로 편제표(결재란 포함), JSON 백업·불러오기, 편제표 CSV, HTML 문서
- **설정** — 학교명, 학년도, 수업 시간(분), 학년별 학급수, 프로젝트 복제·삭제

## 저장과 공유

- 편제 데이터는 **사용하는 브라우저(localStorage)에만 저장**되고 어떤 서버로도 보내지 않습니다.
- 다른 컴퓨터로 옮기거나 동료와 주고받을 때는 **JSON 백업**을 내려받아 상대가 **JSON 불러오기**로 여세요. 불러온 프로젝트는 기존 프로젝트를 덮어쓰지 않고 새 프로젝트로 추가됩니다.
- 이전 claude.ai 아티팩트 버전에서 “JSON 백업”으로 내려받은 파일도 그대로 불러올 수 있습니다.

## 파일 검토에 대해

- 파일은 브라우저 안에서만 읽고 어디에도 보내지 않습니다.
- PDF는 읽기 도구(pdf.js)를 인터넷(jsDelivr)에서 받아 옵니다. 다른 형식은 인터넷 없이 읽습니다.
- 예전 한글(.hwp)과 예전 엑셀(.xls)은 읽을 수 없으니 .hwpx·PDF·.xlsx로 저장해 올려 주세요.
- 서식이 학교마다 달라 잘못 읽을 수 있으니, 검토 전에 화면의 “읽은 표”를 꼭 확인하세요.

## 확인이 필요한 기준

공휴일 표와 일부 기준은 참고 자료입니다. 학년도를 시작하기 전에 교육부 고시 원문과 관보로 꼭 확인하세요.

- 임시공휴일·선거일 지정 여부, 5월 1일(근로자의 날·노동절) 처리
- 제헌절(7월 17일): 2026년 공휴일 재지정 보도를 따라 넣었습니다. 2027년은 토요일이라 대체공휴일 여부를 확인하세요.
- 창의적 체험활동에도 교과(군)처럼 ±20% 증감을 적용할지
- 1~2학년 안전교육 64시간을 창체 안에서 셀지

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위·화면 테스트
npm run coverage   # 커버리지 (80% 미만이면 실패)
npm run build      # dist/index.html 한 파일로 빌드
npm run e2e        # 빌드 결과를 설치된 Chrome으로 열어 핵심 흐름 검사
```

`main` 브랜치에 올리면 GitHub Actions가 테스트, 빌드, 브라우저 검사를 거쳐 GitHub Pages에 배포합니다.

### 구조

```
src/
  data/       2022 개정 시간 배당 기준, 공휴일
  domain/     화면과 무관한 규칙 (시수 합계·판정, 수업일수, 주당 배분, 시간표, 검토, 편집 함수, 불러오기 검증)
  storage/    저장·JSON 가져오기
  state/      앱 상태
  ui/         화면
e2e/          실제 브라우저 흐름 검사
```
